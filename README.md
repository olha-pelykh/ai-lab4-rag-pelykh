# Лабораторна робота №4. Побудова рішення RAG на базі LLM

- **Дисципліна:** Технології ШІ в інженерії даних
- **Варіант:** 12
- **ПІБ:** Ольга Пелих
- **Група:** ПЗ-46
- **Документ:** Microbiology (OpenStax), https://openstax.org/details/books/microbiology
  - Використана частина: сторінки 23–185 оригінального PDF-файлу (163 сторінки, розділи 1–4). Фрагмент збережено у `data/document.pdf`. Усюди в роботі використовуються номери сторінок цього файлу (як їх показує переглядач PDF): сторінка 1 файлу відповідає сторінці 23 оригіналу.
- **Модель ембедингів:** BAAI/bge-small-en-v1.5
- **Чанки A; B:** 256/32; 512/64 (chunk_size/chunk_overlap, токени)
- **LLM:** qwen2.5:3b (Ollama), temperature 0, seed = 12
- **Додатковий експеримент:** Е2, переранжування top-20 cross-encoder `cross-encoder/ms-marco-MiniLM-L-6-v2`

## Запуск

Потрібні Python 3.12, Git та Ollama.

```
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
ollama pull qwen2.5:3b
```

Усі скрипти запускаються з кореня репозиторію, наприклад `python src/ingest.py`. Графіки зберігаються в `reports/figures/`.

## Параметри

Параметри варіанта задано у `src/config.py`. Значення `TOP_K` і `THRESHOLD` початкові, їх буде уточнено за результатами оцінювання пошуку.

## Використання ШІ-асистентів

Розділ буде заповнено наприкінці роботи.
